# SelectiveTunnel 2.0 — нативный клиент Windows

Клиент Windows для ChatGPT/OpenAI Codex/Figma через один внешний SOCKS5/HTTP/HTTPS-прокси. **VPS и домен не нужны.** Остальные домены и обычный интернет идут напрямую. Telegram в этот клиент **не входит** — его держит параллельно запущенный Happ.

Эта версия заменяет PowerShell-сборку 1.1.0. Движок по-прежнему sing-box + Wintun, управление — нативные `SelectiveTunnel.exe` и служба `SelectiveTunnelSvc.exe`.

По умолчанию в форме:

| Поле | Значение |
|---|---|
| Протокол | SOCKS5 |
| IP прокси | `176.119.140.14` |
| Порт SOCKS5 | `14073` |
| Альтернативный порт HTTP | `4073` |

**Логин и пароль в архив не включены.** Вводите данные самого прокси.

## Сборка (Windows x64, MSVC 2022)

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Рядом с `SelectiveTunnel.exe` и `SelectiveTunnelSvc.exe` должны лежать `policy/domains.json` и при наличии офлайн-установки `dependencies/*.zip`. Скопируйте их в каталог выпуска. На Linux собирается только `st_selftest` (проверка конфига/политики, без TUN).

## Сборка (macOS arm64)

macOS-версия (SwiftUI-приложение + LaunchDaemon + sing-box на `utun`) живёт в каталоге `macos/` — см. `macos/README.md`. Кратко:

```bash
cd macos
bash scripts/build.sh
sudo bash scripts/install.sh
```

## Установка на новый ПК

1. Распакуйте выпуск. На ПК с 1.1.0 закройте старое окно и запустите **Update.cmd**: профиль, правила и режим сохранятся, задача PowerShell заменится службой, старые маршруты `198.18.0.0/15` снимутся (они ломали Happ).
2. На новом Windows x64 ПК запустите **Install.cmd**, подтвердите UAC. Если скачивание оборвалось — **Resume-Install.cmd**.
3. Введите логин и пароль прокси. IPv4-туннель включается сразу.
4. Перезагрузите ПК, откройте SelectiveTunnel в «Пуск», нажмите **«Проверить IP»**.

Windows Firewall должен быть включён. Свободны `127.0.0.53:53` и `127.0.0.1:17891`. Не используйте диапазоны `100.82.0.0/16`, `fd71:5e1e:c710::/48`, `172.31.255.0/30`. Чужой NRPT больше не блокирует установку; клиент трогает только свои записи.

## Happ рядом

Happ **Proxy-режим** — для Telegram и прочего трафика. SelectiveTunnel не ставит свой системный прокси и не заворачивает `0.0.0.0/0`. Если Happ включает системный прокси, клиент держит Figma/ChatGPT в списке исключений (`ProxyOverride`), чтобы они шли в TUN, а не в Happ.

Также:

- DNS на `127.0.0.53`, не `127.0.0.1:53`;
- свой FakeIP `100.82.0.0/16`, не `198.18.0.0/15`;
- выход к купленному прокси с физического Ethernet/Wi‑Fi.

Если Happ в TUN перехватывает DNS, добавьте обход `openai.com` / `chatgpt.com` / `figma.com` в Happ. После включения Happ полностью закройте десктоп Figma и ChatGPT/Codex и откройте снова.

## Управление

| Кнопка | Действие |
|---|---|
| Через прокси | Figma и ChatGPT через сохранённый прокси |
| Заблокировать | Эти сайты закрыты, остальной интернет как был |
| Прокси | Адрес, протокол, логин, пароль |
| Проверить IP | Внешний адрес через прокси |
| Ещё | Импорт списка, обновление, диагностика |

Крестик прячет окно, служба продолжает работать. Удаление: **Uninstall.cmd**. Happ не трогается.

## Как сохраняются данные

Профиль — DPAPI LocalMachine в `%ProgramData%\SelectiveTunnel\connection.dpapi`. Конфиг sing-box только через stdin. Blob нельзя копировать между ПК.

SOCKS5/HTTP не шифруют авторизацию до прокси. Режим `https` — только если провайдер даёт TLS до прокси и имя сертификата.

## Только выбранные сервисы

NRPT отправляет DNS выбранных имён на `127.0.0.53`. A-записи заменяются FakeIP `100.82.0.0/16`. Только эти сети идут в TUN. UDP выбранных доменов отклоняется. Нужен **системный DNS**; отключите Secure DNS/DoH в браузерах и Figma/ChatGPT.

Список по умолчанию — `policy/domains.json` (ChatGPT/OpenAI/Figma). Telegram, CDN, платежи и плагины не добавляются автоматически. `cidrs` должен оставаться пустым.

## Проверки

На Windows после сборки:

```bat
SelectiveTunnel.exe --self-test --engine path\to\sing-box.exe --python python
```

Автономные PowerShell-тесты 1.1.0 оставлены как эталон: `tests/Test-Proxy.ps1` импортирует `legacy/client/Core.psm1`. Они не меняют NRPT/firewall.

## Состав

`src/core` — политика, DPAPI, конфиг, guards, IPC; `src/service` — служба SYSTEM; `src/app` — GUI, установка, диагностика; `legacy/client` — PowerShell 1.1.0. MIT. Зависимости проверяются по SHA-256.
