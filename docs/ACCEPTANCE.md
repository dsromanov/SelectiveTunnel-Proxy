# Приёмка прокси-версии

Проводится после установки на двух тестовых ПК. Сейчас выполнены только автоматические локальные проверки из TEST-RESULTS.md.

1. Ввести актуальные данные прокси на каждом ПК. Проверить «Проверить IP»: первая строка одинакова и совпадает с ожидаемым выходным IP; вторая соответствует обычному провайдеру каждого ПК.
2. Проверить `Resolve-DnsName chatgpt.com -Type A` и `Resolve-DnsName www.figma.com -Type AAAA`: должны возвращаться адреса из служебных сетей, не реальные CDN IP. Проверить обычный сайт: его DNS/маршрут остаются прежними.
3. Открыть ChatGPT, выполнить запрос и загрузить файл; выполнить запрос к модели в Codex; открыть файл Figma и проверить совместное редактирование. Проверить браузер и нативное приложение отдельно. Voice/UDP в этой сборке не поддерживаются.
4. Запустить загрузку с обычного сайта одновременно с выбранными приложениями. Она не должна зависеть от прокси.
5. Нажать «Блокировать»: выбранные сайты недоступны, обычные работают. Затем «Подключить»: выбранные восстанавливаются.
6. Временно ввести неверный пароль через «Настройки», нажать «Подключить»: проверка прокси и выбранные сервисы должны завершаться ошибкой, остальные работать напрямую. После теста вернуть верный пароль. Считать статус «Движок работает» подтверждением авторизации нельзя.
7. Повторить проверку при недоступном прокси, завершении движка, перезагрузке, сне/пробуждении, смене Wi-Fi/Ethernet. Отдельно проверить резервные IPv4/IPv6-маршруты на loopback и отсутствие временного прямого доступа.
8. Выполнить захват пакетов на физических адаптерах: выбранные TCP-соединения должны идти на прокси; выбранные реальные назначения и FakeIP не должны уходить напрямую. Существующий до обрыва сеанс также проверить. Одних успешных/неуспешных curl-запросов недостаточно для доказательства отсутствия утечки.
9. Проверить, что после нескольких запусков и изменения пароля в `%ProgramData%\SelectiveTunnel` нет `engine.json`, `profile.json` или других открытых копий данных. Должен присутствовать `connection.dpapi`; доступ только SYSTEM/Administrators. Обычный пользователь не должен читать или изменять каталог установки/данных.
10. Проверить отмену окна настроек: сохранённый пароль не меняется. Пустой пароль при редактировании оставляет старый. После сохранения клиент остаётся заблокированным до «Подключить».
11. Импортировать новую версию списка с дополнительным контролируемым доменом. Проверить применение после «Подключить» и отсутствие прямого окна при переходе. Удалённые из файла домены на клиенте сохраняются.
12. Закрыть приложения/GUI, удалить программу из повышенного PowerShell. Убедиться, что сняты только её собственные правила, выбранные сервисы снова доступны напрямую, остальные настройки не изменились.

Предусловия: системный DNS в приложениях, отключённый DoH/Secure DNS, отсутствие hosts/сохранённых реальных IP и конфликтующей NRPT-политики клиента. Happ может работать параллельно в Proxy-режиме; полный Happ TUN с hijack DNS выводит Figma/ChatGPT из гарантируемой области, пока в Happ не задан обход этих доменов.

До добавления устройств 3–10 подтвердить лимиты тарифа у Proxys.io и провести одновременный тест. Один и тот же прокси не означает автоматически отсутствие ограничения числа соединений со стороны провайдера.
